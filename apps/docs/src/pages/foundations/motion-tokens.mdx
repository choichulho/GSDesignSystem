# Motion Tokens

모션 토큰은 duration과 easing으로 구성합니다. 컴포넌트는 이름이 같은 두 component 토큰을 함께 참조합니다. 정본 이름은 [Token Naming](/develop/token-naming)의 Figma 변수 경로 규칙을 따릅니다.

## 계층과 참조 규칙

| 계층 | Duration | Easing | 소비 규칙 |
| --- | --- | --- | --- |
| Primitive | `$motion/duration/d1` | `$motion/easing/decelerate` | component 구현에서 직접 참조하지 않음 |
| Semantic | 없음 | `$motion/easing/enter` | easing의 용도를 선택할 때 참조 |
| Component | `$motion/duration/dialog-open` | `$motion/easing/dialog-open` | 구현 코드가 함께 참조 |

Duration은 값 자체가 선택 기준이므로 Primitive에서 Component로 alias합니다. Easing은 물리적 커브와 용도를 분리해야 하므로 Primitive → Semantic → Component로 alias합니다.

## Primitive

### Duration scale

| 토큰 | 값 |
| --- | --- |
| `$motion/duration/d1`~`d12` | 50ms~600ms, 50ms 간격 |
| `$motion/duration/d13`~`d16` | 700ms~1000ms, 100ms 간격 |

`d13`~`d16`은 일반 인터랙션에 사용하지 않습니다. 실제 확정 용례가 늘어나지 않으면 스케일 축소를 검토합니다.

### Easing curves

| 토큰 | cubic-bezier |
| --- | --- |
| `$motion/easing/linear` | `cubic-bezier(0, 0, 1, 1)` |
| `$motion/easing/standard` | `cubic-bezier(0.68, 0, 0.28, 1)` |
| `$motion/easing/decelerate` | `cubic-bezier(0.23, 1, 0.5, 1)` |
| `$motion/easing/accelerate` | `cubic-bezier(0.32, 0, 0.67, 0)` |
| `$motion/easing/emphasized` | `cubic-bezier(0.21, 1.28, 0.23, 1.09)` |

`emphasized`의 y 좌표는 1을 넘을 수 있으며, 이는 오버슈트 동작을 의도합니다. Easing은 cubic-bezier만 사용합니다. Spring은 CSS와 값 모델이 달라 이 토큰 체계에 포함하지 않습니다.

## Semantic easing

| 토큰 | Alias | 용도 |
| --- | --- | --- |
| `$motion/easing/default` | `standard` | 역할을 정하기 전의 임시 기본값 |
| `$motion/easing/move` | `standard` | 위치·크기 변경과 화면 내 이동 |
| `$motion/easing/enter` | `decelerate` | 화면 밖에서 안으로 진입 |
| `$motion/easing/exit` | `accelerate` | 화면 밖으로 퇴장·영구적 소멸 |
| `$motion/easing/attention` | `emphasized` | 단발성 transform 강조 |
| `$motion/easing/feedback` | `linear` | color·opacity 등의 즉각 피드백 |

## 확정 Component tokens

아래 항목만 Figma 원본에서 duration과 easing이 함께 확인된 component token입니다. 목록에 없는 컴포넌트의 토큰은 값을 추정해 추가하지 않습니다.

| Component | Duration alias | Easing alias |
| --- | --- | --- |
| `checkbox-select` | `d4` | `feedback` |
| `radio-select` | `d4` | `feedback` |
| `toggle-switch` | `d4` | `feedback` |
| `dialog-open` | `d10` | `enter` |
| `dialog-close` | `d4` | `exit` |
| `sheet-open` | `d10` | `enter` |
| `sheet-close` | `d4` | `exit` |
| `card-expand` | `d10` | `attention` |
| `page-forward` | `d10` | `move` |
| `page-backward` | `d10` | `move` |
| `screen-enter` | `d9` | `enter` |
| `screen-exit` | `d4` | `exit` |

각 행은 `$motion/duration/{name}` 및 `$motion/easing/{name}` 두 토큰을 뜻합니다. 예를 들어 `dialog-open`은 `$motion/duration/dialog-open`과 `$motion/easing/dialog-open`을 함께 사용합니다.

## Reduced Motion 모드

Figma Semantic 컬렉션에 `Default`와 `Reduced` 모드를 둡니다. Reduced 모드에서는 component duration alias를 1ms로 바꾸고, semantic easing은 `linear`로 alias합니다. Figma Motion의 Timing 값은 1ms 이상이어야 하므로 디자인 도구에서는 1ms를 사용합니다.

웹 변환기는 Reduced 값을 다음과 같이 OS 설정에 연결해야 합니다. 이 규칙은 생성물에 적용하며, 컴포넌트별로 반복 작성하지 않습니다.

```css
@media (prefers-reduced-motion: reduce) {
  :root {
    --motion-duration-dialog-open: 1ms;
    --motion-easing-dialog-open: linear;
  }
}
```

자동 재생·반복 동작의 중지는 duration 토큰만으로 보장할 수 없습니다. 해당 기능은 컴포넌트 동작 정책에서 중지해야 합니다.

## DTCG와 플랫폼 출력

Duration은 DTCG `duration`, Easing은 `cubicBezier`로 출력합니다. Figma 내보내기 duration은 초 단위를 사용하므로 변환 단계에서 단위를 확인하고 반올림합니다.

| 플랫폼 | Duration | Easing |
| --- | --- | --- |
| CSS | `500ms` | `cubic-bezier(0.23, 1, 0.5, 1)` |
| Dart | `Duration(milliseconds: 500)` | `Cubic(0.23, 1, 0.5, 1)` |
| Android | `500L` | `PathInterpolator(0.23f, 1f, 0.5f, 1f)` |
| iOS | `0.5` 초 | `CAMediaTimingFunction(controlPoints:)` |

## 파이프라인 검증

토큰 빌드는 다음을 CI에서 검증해야 합니다.

1. Component duration 키와 component easing 키의 집합이 정확히 일치해야 합니다.
2. 모든 component token은 허용된 Primitive 또는 Semantic token을 alias해야 합니다.
3. Easing 값은 cubic-bezier여야 하며 Spring 값을 허용하지 않습니다.
4. Default와 Reduced 모드에 동일한 component 키가 존재해야 합니다.
5. Duration의 초 단위 변환 결과는 플랫폼 출력에서 정해진 정밀도로 반올림해야 합니다.

## 보류 중인 설계 결정

- Easing이 5종인지 6종인지 Figma 원본에서 확인해야 합니다.
- `dropdown`, `menu`, `snackbar`, `button-hover`, `textfield-focus`는 duration 근거를 확정한 뒤 component token으로 추가합니다.
- carousel의 사용자 조작 슬라이드와 auto-advance의 전환 duration·대기 interval을 분리해 정의해야 합니다.
