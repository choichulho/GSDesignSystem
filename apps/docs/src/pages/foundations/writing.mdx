# UX Writing

> GS SHOP 고객이 앱을 효율적으로 사용하고 탐색할 수 있도록 인터페이스 텍스트를 작성하는 가이드입니다.

UI 텍스트는 상품 발견부터 구매, 구매 후 경험까지 고객 여정 전체를 연결합니다. 고객이 정보와 서비스를 쉽게 이해하고 자연스럽게 탐색·사용하여 GS SHOP을 신뢰할 수 있도록 작성합니다.

## 주요 특징

- 고객이 이해하기 쉬운 언어와 일관된 어조를 사용합니다.
- 질문·행동 유도·정보 전달 상황에 맞는 종결 표현을 사용합니다.
- 용어, 숫자, 단위, 문장부호를 표준화해 혼란을 줄입니다.

## 사용 시점 (When to Use)

1. **UI 텍스트를 새로 작성할 때** — 버튼, 대화창, 오류·상태 메시지, 안내 문구에 적용합니다.
2. **기존 문구를 검토할 때** — 고객 중심성, 간결성, 정확성, 일관성을 확인합니다.
3. **용어를 결정할 때** — 동의어가 여러 개인 경우 이 문서의 표준 용어를 사용합니다.

### 사용하지 않는 맥락 (When NOT to Use)

- 광고 캠페인의 브랜드 메시지 → 브랜드·마케팅 카피 가이드를 사용하십시오.
- 법적 고지의 정확한 문구 → 관련 법무 검토 문서를 우선하십시오.

## Voice and Tone Principles

GS SHOP은 고객의 구매 여정을 함께하는 **믿을 수 있는 안내자**처럼 말합니다. 친근하고 이해하기 쉬우며, 정확하고 일관된 언어를 사용합니다.

| 원칙 | 한 줄 설명 |
| :-- | :-- |
| **친근하게** | 사람과 대화하듯 따뜻하고 인간적으로 씁니다. |
| **이해하기 쉽게** | 누구나 알 수 있는 용어로 간단한 단어와 문장을 사용합니다. |
| **정확하고 분명하게** | 어문 규범에 맞고 의미가 모호하지 않게 씁니다. |
| **일관되게** | 같은 의미는 하나의 용어와 어조로 통일합니다. |

## 친근하게 써요

고객이 존중받는 느낌을 받도록 따뜻하고 인간적인 메시지를 작성합니다.

### 사람과 대화하듯이 쓰기

상호작용이 필요한 화면에서는 친근한 **해요체**를 사용하고, 정책·상태 등 단순 정보를 전달할 때에는 전문적이고 신뢰감 있는 **합니다체**를 사용합니다.

#### 질문하거나 행동을 유도할 때 — 해요체

고객이 선택하거나 결정해야 하는 대화창에서 부담을 줄이기 위해 해요체를 사용합니다.

![선택을 유도하는 대화창 예시](/foundations/writing/friendly-ex1.png)

#### 요청할 때 — `~하세요`보다 `~해주세요`

정보 입력이나 동의를 요청할 때는 더 부드러운 표현을 사용합니다.

![요청 표현 예시](/foundations/writing/friendly-ex4.png)

- 🚫 서비스 약관에 동의하시겠습니까?
- 🚫 서비스 약관에 동의하세요.
- ✅ 서비스 약관에 동의해주세요.

#### 단순 정보 전달 — 합니다체

이용약관, 개인정보처리방침, 운영정책처럼 정책과 상황을 알리는 문구에는 합니다체를 사용합니다.

![정보 전달 표현 예시](/foundations/writing/friendly-ex5.png)

- 🚫 폭설과 한파로 배송이 지연될 수 있어요.
- ✅ 폭설과 한파로 배송이 지연될 수 있습니다.

### 고객 중심의 언어 사용하기

#### 부정적 표현은 긍정적으로 바꿔 씁니다

- 🚫 쿠폰은 중복 적용이 불가합니다. → ✅ 할인 쿠폰은 한 상품에만 적용됩니다.
- 🚫 이 상품은 단품으로는 판매하지 않습니다. → ✅ 이 상품은 세트로만 판매합니다.
- 🚫 주문이 취소되었습니다. 배송 기사에게 연락이 오면 수락 거절해주세요. → ✅ 주문이 취소되었습니다. 배송 기사에게 연락이 오면 취소했다고 말씀해 주세요.

#### 고객의 입장을 배려합니다

- 🚫 고객 과실(단순 변심)로 반품하실 때에는 반품비는 고객님 부담입니다.
- ✅ 상품 불량이 아닌 다른 사유로 반품하실 때에는 반품비를 고객님께서 부담해 주셔야 합니다.

`고객 과실`, `고객 사유`처럼 고객을 탓하는 인상을 주는 말은 사용하지 않습니다.

#### 고객의 입장에서 표현합니다

`지급`, `부여`, `드립니다` 대신 고객이 혜택을 **받는다**고 느끼는 표현을 사용합니다.

![고객 관점 표현 예시](/foundations/writing/friendly-ex2.png)

- 🚫 3,000원 할인 쿠폰이 지급됩니다. → ✅ 3,000원 할인 쿠폰을 받으실 수 있어요.
- 🚫 사은품 증정 대상 상품입니다. → ✅ 이 상품을 주문하시면 사은품을 받으실 수 있어요.
- 🚫 상품은 내일 배송됩니다. → ✅ 상품은 내일 받으실 수 있습니다.

### 자연스러운 언어 사용하기

- 🚫 사용 가능합니다. → ✅ 사용하실 수 있습니다.
- 🚫 고객센터로 연락 요망. → ✅ GS SHOP 고객센터로 연락해 주세요.
- 🚫 반품 신청하신 상품은 00월 00일 수거 예정으로 받으셨던 대로 미리 포장 부탁드립니다. → ✅ 반품 신청하신 상품은 00월 00일에 수거할 예정입니다. 처음에 받으셨던 대로 미리 포장해 주시면 감사하겠습니다.

## 이해하기 쉽게 써요

고객은 화면을 훑으며 단어와 문장을 선별해 봅니다. 누구나 이해할 수 있도록 짧고 간결하게 쓰되 핵심은 빠뜨리지 않습니다.

### 간결하고 짧게 쓰기

한 문장에는 하나의 메시지만 담고 꼭 필요한 정보만 남깁니다.

- 🚫 스마트폰, 태블릿에서는 공인인증서 없이 간편하게 이용할 수 있습니다. → ✅ 공인인증서 없이 간편하게 이용할 수 있습니다.
- 🚫 오늘 발생한 전국적 통신장애로 데이터 복구가 늦어지고 있어 고객님이 주문하신 상품 배송이 늦어지고 있습니다. → ✅ 시스템 오류로 배송이 지연되고 있습니다.
- 🚫 인증 오류가 발생했습니다. → ✅ 입력한 비밀번호가 잘못되었습니다.
- 🚫 이 페이지에 액세스하려면 승인된 사용자여야 합니다. → ✅ 댓글을 작성하려면 로그인하세요.

![간결한 안내 예시](/foundations/writing/clarity-ex2.png)

불필요한 꾸밈말과 중복을 줄입니다.

- 🚫 고객님께 연락이 되지 않아 상품은 부득이하게 반송 처리하였습니다. → ✅ 고객님과 연락이 되지 않아 상품을 반송하였습니다.
- 🚫 메일이 성공적으로 발송되었습니다. → ✅ 메일이 발송되었습니다.
- 🚫 주문하신 상품을 모두 일괄 반품하시겠어요? → ✅ 주문하신 상품을 모두 반품하시겠어요?
- 🚫 현재 전산 오류로 인한 시스템 장애로 배송 정보 확인이 어렵습니다. → ✅ 지금 전산 오류 때문에 배송 정보를 확인하기 어렵습니다.

`정말`, `참`, `매우`, `성공적으로`, `처리`, `적용`, `완료`처럼 의미를 더하지 않는 말은 가급적 사용하지 않습니다.

![군더더기 제거 예시](/foundations/writing/simple-ex1.png)

### 쉽게 풀어서 쓰기

전문용어, 줄임말, 낯선 한자어와 외래어를 고객이 이해할 수 있는 쉬운 표현으로 바꿉니다.

#### UI 관련 전문 용어

| 피할 표현 | 쉬운 표현 |
| :-- | :-- |
| 팝업, 팝업창, Pop-up | 알림창 |
| 링크, URL | 인터넷 주소 |
| 에러 | 오류 |
| 재부팅 | 재시작 |
| 체크 | 선택 |
| 드래그 앤 드롭 | 끌어다 놓기 |
| Sync | 동기화 |
| Help | 도움말 |
| 클릭, 터치 | 누르다 |
| 토글 버튼 | 제외 버튼 |
| Dialog, 다이얼로그 | 대화창 |
| 로딩 중 | 준비 중 |
| 활성화 | 켜다 |

- 🚫 오른쪽 토글 버튼을 클릭해보세요. → ✅ 오른쪽 제외 버튼을 눌러보세요.
- 🚫 버퍼링 → ✅ 동영상 준비 중

#### 한자어 접두사와 줄임말

| 피할 표현 | 쉬운 표현 |
| :-- | :-- |
| 기가입 고객, 기등록 고객 | 이미 가입한 고객 |
| 미가입 고객, 미등록 고객 | 아직 등록하지 않은 고객 |
| 미배송, 미수령, 미수취 | 아직 배송되지 않은 |
| 선환불 | 즉시 환불 |
| 선수거 후 배송 | 상품을 먼저 수거한 후 배송 |
| 재입고 알림 | 주문 가능 알림 |
| 재주문 | 다시 주문 |
| 합결제 | 한꺼번에 결제 |
| 비번 | 비밀번호 |
| 실번호 | 실제 사용하는 휴대폰 번호 |
| 맞교환 | 배송과 수거를 동시에 하는 상품 교환 |
| 셀프 반품 신청 | 고객이 직접 반품 신청 |

`재입고 알림`은 단순히 `다시`로 풀기보다 고객이 바로 이해할 수 있는 `주문 가능 알림`으로 씁니다.

### 일상적인 단어 사용하기

#### 낯선 한자어

| 피할 표현 | 쉬운 표현 |
| :-- | :-- |
| 순차 배송 | 차례대로 배송 |
| 출고 전, 출하 지시 | 상품 준비 중 |
| 위탁 | 맡김, 맡겨 둠 |
| 분리 발송, 별도 배송 | 따로 배송 |
| 속성, 옵션, 선택 | 고객의 선택 |
| 사후 지급 혜택 | 행사 종료 후 고객이 받을 수 있는 혜택 |
| 제세공과금 | 각종 세금 |
| 수령, 수취 | 상품을 받음 |
| 수령인, 수취인 | 상품을 받는 분 |
| 이관 | 전달 |
| 차액 | 나머지 금액 |
| 차감 | 뺌 |
| 환불 계좌 | 환불받을 계좌번호 |
| 지정일 배송 | 고객이 요청한 날짜에 상품이 도착 |
| 택배 수거 | 배송 기사가 방문하여 상품 수거 |

앱에서 색상, 사이즈, 수량을 뜻할 때에는 `옵션`보다 `선택`을 사용합니다. `부여`, `증정`도 고객 관점의 `받음`으로 바꿉니다.

#### 외래어와 혼합어

| 피할 표현 | 쉬운 표현 |
| :-- | :-- |
| 코드, 번호 | 번호 |
| 태그 제거, 택 제거 | 옷 등에 붙어 있는 태그 제거 |
| FAQ | 자주 묻는 질문 |
| 핫플레이스 | 인기 장소 |
| 입소문템 | 입소문 난 물건 |
| 필수템 | 필수 아이템 |

## 정확하고 분명하게 써요

정확한 표현은 고객의 신뢰를 높이고, 분명한 표현은 오해와 궁금증을 줄입니다.

### 정확한 표현 사용하기

#### 어문 규범과 띄어쓰기

| 틀린 표현 | 정확한 표현 |
| :-- | :-- |
| 생산 년도 | 생산 연도 |
| 남여 공용 | 남녀 공용 |
| 몇 일, 몇일 | 며칠 |
| 조금 이따가 | 이따가, 조금 있다가 |
| 즉시할인 | 즉시 할인 |
| 2주내, 결제시, 배송후 | 2주 내, 결제 시, 배송 후 |
| 배송완료 | 배송 완료 |
| 방송중특가 | 방송 중 특가 |

조사·의존명사·단위는 띄어 쓰며, `겸`, `내지`, `대`, `등`, `및` 앞도 띄어 씁니다. 하나의 기능을 가리키는 고유용어에 가까운 경우에는 붙여 씁니다. 예: `사전예약가`, `카드할인가`.

#### 외래어와 어법

| 틀린 표현 | 정확한 표현 |
| :-- | :-- |
| 어플, 어플리케이션 | 앱, 애플리케이션 |
| 컨텐츠 | 콘텐츠 |
| 벳지 | 배지 |
| 푸쉬 | 푸시 |
| 이 상품으로 보시게 되면 | 이 상품을 보시면 |
| 상품 선택에 있어서 | 상품을 선택할 때에는 |
| 오늘 같은 경우에는 | 오늘은 |

#### 올바른 높임 표현

| 잘못된 표현 | 올바른 표현 |
| :-- | :-- |
| 상품이 불량이시면 반품할 수 있습니다. | 불량 상품은 반품할 수 있습니다. |
| 전화번호가 어떻게 되세요? | 전화번호를 말씀해 주시겠어요? |
| 조절이 가능하신 부분이세요. | 조절이 가능합니다. |
| 양해 말씀드립니다. | 양해해 주시기 바랍니다. |
| 주문 도와드리겠습니다. | 주문하시겠습니까? |

### 분명한 표현 사용하기

| 모호한 표현 | 분명한 표현 |
| :-- | :-- |
| 도서 산간 배송비 | 도서 산간 지역 추가 배송비 |
| 영업일 기준 5일 이내에 수거 처리해 드리겠습니다. | 주말과 공휴일을 제외하고 5일 이내에 수거하겠습니다. |
| 상품, 제품, 물품, 물건 | 상품 |
| 출고, 발송, 상품 출발 | 발송 |
| 택배, 배송 | 배송 |
| 깔별로 | 색깔별로 |
| 강추 | 강력하게 추천 |
| 무배 | 무료 배송 |
| 1 DAY | 단 하루 |
| Special Price | 특가, 특별 할인가 |

## 일관되게 써요

같은 의미는 하나의 용어와 어조로 통일합니다. 일관성 없는 인터페이스는 고객을 혼란스럽게 만듭니다.

### 용어와 표현 표준

| 후보 용어 | 표준 용어 |
| :-- | :-- |
| 구성, 구성품, 구성 상품, 상품 구성, 추가 구성 | 구성 상품 |
| Customer, 소비자, 회원, 유저, 사용자, 이용자, 구매자 | 고객 |
| 아이디, ID, 회원 ID | 아이디 |
| 비밀번호, 비번, 패스워드 | 비밀번호 |
| 등록, 작성, 쓰기 | 작성 |
| 고지, 공지, 안내, 알림 | 알림, 알려 드림 |
| 모바일, 핸드폰, 휴대폰 | 휴대폰 |
| 모바일 전화번호, 핸드폰 번호, 연락처 | 휴대폰 번호 |
| 이메일 주소, 이메일, e메일, email | 이메일 주소 |
| 메인, 홈, Main, Home | 홈 |
| 클릭, 터치 | 누름 |
| 체크 | 확인 |
| 스크린, 페이지 | 화면 |

![용어 일관성 예시](/foundations/writing/consistency-ex1.png)

- 🚫 회원님! 아래 버튼을 클릭해서 새 비밀번호를 설정해 주세요. → ✅ 고객님! 아래 버튼을 눌러서 새 비밀번호를 설정해 주세요.
- 🚫 상품 리뷰를 등록해 주시면 사은품을 드려요. → ✅ 상품 리뷰를 작성해 주시면 사은품을 받으실 수 있습니다.

### 배송 관련 표현

| 후보 용어 | 표준 용어 |
| :-- | :-- |
| 기사, 기사님, 배송원, 택배원, 택배 기사 | 배송 기사 |
| 전담, GS 전담, GS SHOP 전담 배송 | GS SHOP 전담 배송 |
| 배송사, 택배사 | 배송사 |
| 배송 송장, 송장, 운송장 | 운송장 |
| 배송 준비, 주문 발주, 출하 지시, 출고 전 | 상품 준비 중 |

고객에게는 “주문하신 상품은 00월 00일에 발송하였으니 00월 00일~00월 00일에 받으실 수 있습니다.”처럼 발송과 수령 시점을 명확하게 안내합니다.

### 상품명, 숫자, 단위

- 상품명은 해당 회사의 표기 규정을 따르며 대소문자와 띄어쓰기를 지킵니다. 예: `Windows`, `macOS`, `iPhone`, `iPad`, `iOS`, `Android`.
- 상품군은 한글로 쓰고, 통상 영어로 쓰는 상품명은 영어로 표기합니다. 예: `스마트폰`, `태블릿`, `PC`.
- 상품 포장에 나온 상품명은 표준 맞춤법과 달라도 원문을 유지합니다. 예: `해태 부라보콘`, `오뚜기 진라면`, `설레임`.
- 숫자는 연도·백분율 등을 제외하고 1,000자리마다 쉼표를 씁니다.
- 용량과 치수 단위는 소문자로 통일합니다. `50g`, `2kg`, `250ml`, `30cm`, `4m`.

### 문장부호

| 문장부호 | 사용 규칙 | 예시 |
| :-- | :-- | :-- |
| 물결표 `~` | 기간·거리·범위를 나타내며 앞뒤에 붙입니다. | `11월 1일~12월 31일` |
| 슬래시 `/` | 유사 카테고리나 상품명을 나열하며 앞뒤에 붙입니다. | `경영/경제 도서`, `주문/배송 조회` |
| 가운뎃점 `·` | 메뉴·버튼에서 가독성을 위한 구분에만 사용합니다. | `주문·배송` |
| 콜론 `:` | 앞은 붙이고 뒤는 한 칸 띄웁니다. 시간은 붙여 씁니다. | `결제 중: 신한카드`, `12:00` |
| 파일 확장자 | 소문자 확장자 앞에 마침표를 씁니다. | `.exe`, `.apk`, `.pdf` |
| 대괄호 `[ ]` | 페이지·메뉴 이름과 버튼 레이블을 나타냅니다. | `[다음]을 눌러주세요.` |

![대괄호 사용 예시](/foundations/writing/clarity-ex3.png)

### 버튼 레이블

버튼 레이블은 동사형을 기본으로 씁니다. 짧은 레이블에는 `하기`를 붙이고, 긴 레이블에서는 필요에 따라 생략합니다. 공간이 좁으면 짧게 쓸 수 있습니다.

| 권장 표현 | 비권장 표현 |
| :-- | :-- |
| 사용자 글꼴 설정 | 사용자 글꼴 설정하기 |
| 구매하기 | 구매 |
| 임시 데이터 삭제 | 임시 데이터 삭제하기 |
| 선물하기 | 선물 |

### 날짜와 시간

날짜와 시간은 고객이 자주 혼동하는 정보입니다. 표기 규칙을 통일해 중요한 정보를 빠르게 전달하십시오. 세부 규칙은 Date & Time 가이드에서 관리합니다.

## 사용 가이드라인 (Do / Don't)

### ✅ Do

- 고객의 행동과 선택을 돕는 쉬운 문장으로 씁니다.
- 한 문장에 하나의 핵심 메시지를 담습니다.
- 고객 관점의 `받다`, `도착하다`, `상품 준비 중` 같은 표현을 사용합니다.
- 용어와 문장부호 표준을 모든 화면에서 동일하게 적용합니다.

### ❌ Don't

- 전문용어, 줄임말, 내부 용어를 고객에게 그대로 노출하지 마십시오.
- 고객에게 책임을 돌리거나 부정적인 인상을 주는 표현을 사용하지 마십시오.
- 같은 개념을 화면마다 다른 용어로 표현하지 마십시오.
- `클릭`, `터치`처럼 입력 방식에 의존하는 말을 사용하지 마십시오. `누르다`로 통일하십시오.

## 접근성 (Accessibility)

- 쉬운 단어와 짧은 문장을 사용해 인지 부담을 줄입니다.
- 상태·오류·다음 행동을 분명하게 알려 스크린 리더 사용자도 맥락을 이해할 수 있게 합니다.
- 색상만으로 정보를 전달하지 않고 텍스트로 상태와 의미를 함께 안내합니다.
- 버튼 레이블은 동사형으로 작성해 실행 결과를 예측할 수 있게 합니다.
