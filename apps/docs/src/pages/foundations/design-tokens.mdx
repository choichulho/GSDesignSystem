# Design Tokens

토큰은 Figma Variables를 단일 원천으로 하며, 파이프라인이 자동으로 동기화한다.

## 계층 구조

Primitive → Semantic → Component 3계층을 따른다. Semantic 토큰은 Primitive를
참조(`{color.gsblue.500}`)로 가리키며, 빌드 시 CSS 변수의 `var()`로 보존된다.

## 갱신 흐름

1. Figma Variables를 수정한다.
2. GitHub Actions의 **Sync Tokens from Figma**를 실행한다.
3. 봇이 `packages/tokens`를 갱신 커밋하면 사이트가 재배포된다.

```css
/* build/tokens.css 출력 예시 */
:root {
  --color-content-primary: var(--color-gray-900);
}
[data-theme="dark"] {
  --color-content-primary: var(--color-gray-50);
}
```
