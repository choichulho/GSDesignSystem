# Button

버튼은 사용자가 동작을 실행하게 하는 기본 인터랙션 요소다.

## Variants

| Variant | 용도 |
|---------|------|
| Primary | 화면의 대표 동작이다 |
| Secondary | 보조 동작이다 |
| Ghost | 낮은 강조의 동작이다 |

> 이 표는 추후 `components.json`(export-components 산출물)에서 자동 생성한다.

## Usage

- 한 화면에 Primary 버튼은 하나만 둔다.
- 파괴적 동작에는 확인 다이얼로그를 함께 쓴다.

## Accessibility

- 최소 터치 영역 44×44px을 지킨다.
- 아이콘만 있는 버튼에는 `aria-label`을 부여한다.
