# Button

버튼(Buttons)은 사용자가 **특정 행동을 취하고, 선택을 확정하며, 흐름(Flow)을 앞으로 진행**할 수 있도록 돕는 컨트롤(조작 요소)입니다.

## Anatomy

- Container
- Label
- Leading Icon (optional)
- Trailing Icon (optional)

## Variants

| Variant | 용도 |
| --- | --- |
| Primary | 화면의 대표 동작입니다 |
| Secondary | 보조 동작입니다 |
| Ghost | 낮은 강조의 동작입니다 |

> 이 표는 추후 `components.json`(export-components 산출물)에서 자동 생성합니다.

## Sizes

| Size | Height | Padding | Font |
| --- | --- | --- | --- |
| S | - | - | - |
| M | - | - | - |
| L | - | - | - |

> 사이즈 값은 Figma 컴포넌트 스펙과 동기화됩니다. `components.json` 파이프라인 연결 후 자동으로 채웁니다.

## States

- default
- hover
- pressed
- focus
- disabled
- loading

## Usage

- 한 화면에 Primary 버튼은 하나만 둡니다.
- 파괴적 동작에는 확인 다이얼로그를 함께 사용합니다.

## Token Mapping

| Property | Token |
| --- | --- |
| Background (default) | - |
| Background (hover) | - |
| Background (pressed) | - |
| Background (disabled) | - |
| Text (default) | - |
| Text (disabled) | - |
| Border | - |
| Radius | - |
| Padding | - |
| Font | - |

> 토큰 매핑은 Component 계층 토큰(`components.json`)에서 자동 생성합니다.

## Do / Don't

**Do**
- 화면당 Primary 1개를 권장합니다

**Don't**
- opacity로 disabled 표현은 사용하지 않습니다

## Accessibility

- 최소 터치 영역 44×44px을 준수합니다.
- 아이콘만 있는 버튼에는 `aria-label`을 부여합니다.
