# Overview

GS 디자인 시스템은 Web·Android·iOS·Flutter를 아우르는 GSSHOP의 디자인 시스템이다.

## 구성

- **Foundations** — 색상·타이포그래피 같은 기초 요소와 디자인 토큰을 정의한다.
- **Components** — 제품을 구성하는 재사용 가능한 UI 컴포넌트를 제공한다.
- **Develop** — 토큰·아이콘 패키지와 프레임워크별 구현 가이드를 안내한다.
- **AI & Tools** — AI 에이전트가 시스템을 정확히 읽고 쓰도록 돕는 자산을 제공한다.

## 원천과 자동화

Figma가 단일 원천이다. 토큰과 아이콘은 파이프라인이 자동으로 동기화하며,
사이트는 그 산출물(`tokens.json`, `icons.json`)을 소비해 렌더한다.
